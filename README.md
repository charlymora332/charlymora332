### Sobre mí

Soy un **desarrollador Full Stack** con más de **2 años de formación y experiencia práctica**, especializado en **React para frontend** y con sólida experiencia en **backend con .NET**, desarrollando **APIs RESTful** usando **Entity Framework Core** y aplicando **arquitectura limpia** con patrones de diseño. Me apasiona crear **soluciones web innovadoras, funcionales, escalables y con accesibilidad para todos los usuarios**.  

- 💻 **Especialidades:** Desarrollo frontend moderno con React, interfaces atractivas y responsivas; integración backend con .NET y APIs RESTful, optimizando la experiencia del usuario.  
- 🌐 **Proyectos destacados:** E-commerce, plataformas de adopción de mascotas y juegos de preguntas interactivos.  
- 🤝 **Habilidades blandas:** Liderazgo, resolución de problemas, mentoría de compañeros y pensamiento lógico aplicado al desarrollo.
